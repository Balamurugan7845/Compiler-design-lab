YACC Arithmetic Expression Parser - One Click Windows

Double-click RUN.bat. It installs/checks WSL packages (Flex, Bison, GCC), generates the parser, compiles it, and runs it.

First-time Windows setup may require a restart and Ubuntu first-time setup. After that, run RUN.bat again.

Try: 10+20*5
Valid: (10+20)*5
Invalid: 10+*20
